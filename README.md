# EMI Calculator (Excel)

A simple EMI Calculator created using Microsoft Excel.

## Features
- Calculate Monthly EMI
- Calculate Total Interest
- Calculate Principal Amount
- User-friendly input fields

## Inputs
- Loan Amount
- Interest Rate
- Loan Duration (Years)
- Down Payment

## Output
- Monthly EMI
- Total Interest Payable
- Principal Amount

## Tools Used
- Microsoft Excel
- Excel Formulas

## Project Type
Beginner Finance Calculator

## Additional Features
- Protected Formula Cells
- User Input Only Design
- Error Prevention
